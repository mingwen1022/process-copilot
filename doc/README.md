# Doc Directory

`doc/` 按文档用途归档。**当前主线文档是 [`产品功能全景.md`](产品功能全景.md)**（按功能模块的设计/现有/要做全景），其余为支撑参考与历史归档。

## 目录

- 根目录 `产品功能全景.md`：**主线文档**，按功能模块盘点设计/现有/要做。
- 根目录 `eval_summary.md`：跨案例评测汇总表（自动导出）。
- `architecture/`：仍有效的架构与设计参考（流程定义 schema、评测策略、架构图）。
- `references/`：真实业务样例与制度文档（规则 RAG 的语料来源）。
- `prototypes/`：仍对齐主线的 HTML 原型（AI 设计台、运行沙盒 demo）。
- `archive/`：**历史文档**（V1 状态快照、旧项目计划、重定位与执行规划、重运行时/OA 方向的 PRD 与原型）。仅留档，不再维护。

## 关键入口

- 主线全景：`产品功能全景.md`
- 流程定义 Schema：`architecture/process_definition_schema.md`
- 评测策略：`architecture/langgraph_eval_strategy.md`
- 流程分析 Agent 架构图：`architecture/流程分析agent_architecture.drawio`
