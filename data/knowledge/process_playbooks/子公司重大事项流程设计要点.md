# 子公司重大事项流程设计要点（合成）

面向子公司重大事项审批备案流程（EOA140）的设计范例，供设计 agent 参考。

## 一、多枢纽会签设计

该流程横跨子公司与总部对口部门，是典型的**多枢纽 + 并行会签**结构：子公司内部
审核 → 高管审批 → 申请人分发 → 对口部门逐级会签 → 公司领导批示 → 备案归档。
设计时对口部门处理应用多选-并行处理，确保多部门意见并行收集。

## 二、分发枢纽

"申请人分发""对口部门专员分发"是流转枢纽环节，负责按事项类型把单子派到正确
的对口部门，是该流程的关键路由点，不可省略。

## 三、归档

批示完毕须有明确的备案/归档收口环节，保证全程留痕可追溯。

## 四、常见反模式

1. 跳过对口部门会签直接批示——重大事项缺少职能把关。
2. 分发环节缺失，导致单子无法路由到正确对口部门。
